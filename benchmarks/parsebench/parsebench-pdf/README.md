# ParseBench (PDF) — Trunchbull Repository

Unofficial Trunchbull port of [ParseBench](https://github.com/run-llama/ParseBench)
(LlamaIndex, Apache-2.0). Not maintained by or affiliated with the upstream
project. Each case attaches the original single-page document (PDF, or the
source image for the few image-sourced pages) and asks the model to parse it
into layout-annotated markdown. `grader/` scores the output with upstream
ParseBench's own evaluation.

This directory is one self-contained Repository. Its sibling
`parsebench-image` is a separate Repository with the same grader context.
Both contexts have the same digest, so they share one grader image. Sources,
pins, licensing, parity results and known differences from upstream are
documented in the port's top-level `README.md` and `provenance.json` in
[TrunchbullCI/examples](https://github.com/TrunchbullCI/examples/tree/main/benchmarks/parsebench).

`documents/` (attachments) and `grader/rules/` (rules baked into the grader
image) are dataset files. They are generated by the port's `tools/prepare.sh`
from the pinned dataset revision and never committed: in this Repository they
are protected objects, with pointers in Git and the bytes in R2
(`.trunchbullignore`). Do not mirror this Repository publicly.
