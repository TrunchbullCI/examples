# BoolQ Trunchbull port

This zero-dependency port contains the complete 3,270-case labeled validation
split. Each case preserves the original passage and question and evaluates a
binary `YES` or `NO` answer. The deterministic `answer_bank` evaluator requires
the model to end with `FINAL ANSWER: YES` or `FINAL ANSWER: NO`.

The original BoolQ repository publishes the development split as `dev.jsonl`,
but its historical Cloud Storage download is no longer anonymously readable.
This port vendors the equivalent validation split from the pinned
[`google/boolq`](https://huggingface.co/datasets/google/boolq) Parquet mirror,
normalizes it to canonical JSONL, and records the upstream repository revision,
mirror revision, split count, and vendored source hash in `provenance.json`.

The immutable JSONL export and hash receipt are generated by Trunchbull's
benchmark publication workflow.

BoolQ is released under the Creative Commons Attribution-ShareAlike 3.0
license. Its paper is [BoolQ: Exploring the Surprising Difficulty of Natural
Yes/No Questions](https://arxiv.org/abs/1905.10044).
